## Descrição da atividade

Projeto desenvolvido em Flutter para praticar a estrutura de uma aplicação,
o uso de Widgets, a organização da interface, a interação com botões e a
atualização de informações na tela com `setState`.

## Descrição da aplicação

O **Meu Progresso** é um contador simples de tarefas de estudo. O usuário pode
registrar cada tarefa concluída durante o dia e acompanhar uma mensagem que
muda de acordo com seu progresso.

## Funcionalidades

- Exibição da quantidade de tarefas concluídas;
- Botão para adicionar uma tarefa concluída;
- Mensagem de incentivo atualizada automaticamente;
- Botão para zerar o contador;
- Interface simples e adaptável a diferentes tamanhos de tela.

## Como executar o projeto

1. Tenha o Flutter SDK e um emulador Android instalados;
2. Abra a pasta do projeto no VS Code;
3. Abra um emulador ou conecte um dispositivo Android;
4. No terminal, execute `flutter pub get`;
5. Depois, execute `flutter run`.
